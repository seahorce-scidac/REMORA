This small idealized grid is used to test netCDF-provided river sources.
The ocean is initialized with zero velocity and a constant
temperature and salinity. Rivers have 0 salinity.

The netCDF files needed to run these tests can be found in the
`remora-data <https://github.com/seahorce-scidac/remora-data>`_
repository under the ``IdealRivGrid`` directory.
